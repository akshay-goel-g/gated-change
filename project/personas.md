# Persona rules

> Yours. How this project's gate personas think, beyond the portable defaults in
> `core/02-gates.md`. Rules are added by the process in `core/11-evolution.md` —
> not by editing this file mid-conversation because something sounded right.

**Budget: 7 items per gate.** At the budget, one in means one out. If everything feels
essential, the gate is doing two jobs and should be split.

---

## Before adding anything here

- [ ] Routed correctly? (**what to check** → registry · **when to worry** → surfaces ·
      **what to know** → template · **how to think** → here)
- [ ] Evidence tier named: anecdote / pattern / incident / universal
- [ ] Anecdote → do **not** persist. Apply now, note it in the intent log
- [ ] Backtested against the last 5–10 changes, with the result recorded
- [ ] Falsifiable — there is an answer that would stop a change
- [ ] Checked against existing rules for contradiction
- [ ] Under budget, or one named for removal

---
